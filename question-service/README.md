# Question endpoints
## POST (get) random with difficulty and categories - http://localhost:3013/question/random/
body : 
```
{
    "difficulty" : "hard",
    "categories" : ["Data Structures", "Algorithms"]
}
```

example response : 
```
{
    "_id": "68f34ca9f5d7e97b5349d0ed",
    "QuestionTitle": "N-Queen Problem",
    "QuestionDescription": "Return all distinct solutions to the n-queens puzzle.",
    "QuestionCategories": [
        "Algorithms"
    ],
    "QuestionComplexity": "hard",
    "__v": 0,
    "questionScore": 10
}
```

errors : 404 if no question exists with specified difficulty and topic combination

## GET by id - http://localhost:3013/question/:id
id is autogenerated by mongo eg 68f34cdcf5d7e97b5349d0f8

## DELETE by id - http://localhost:3013/question/:id

## POST - http://localhost:3013/question
example body : 
```
{
    "QuestionTitle": "unique test q200",
    "QuestionDescription": "test q desc",
    "QuestionComplexity" : "easy",
    "QuestionCategories" : ["TESTCAT"]
}
```

## PUT - http://localhost:3013/question/:id
example body : 
```
{
    "QuestionCategories" : ["cat 1", "cat 2"],
    "QuestionTitle": "changed 23"
}
```

## GET all - http://localhost:3013/question/all

# Question attempt endpoints

## add question attempt : POST - http://localhost:3013/question/attempt
example body : 
```
{
  "Username": "testuser",
  "QuestionId": "testID",
  "IsCorrect": "false",
  "QuestionTitle":"2sum"
}
```
